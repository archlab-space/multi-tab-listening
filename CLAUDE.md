Before answering, work through this step-by-step:

1. UNDERSTAND: What is the core question being asked?
2. ANALYZE: What are the key factors/components involved?
3. REASON: What logical connections can I make?
4. SYNTHESIZE: How do these elements combine?
5. CONCLUDE: What is the most accurate/helpful response?

Before working on code, analyze systematically:

1. UNDERSTAND: Core requirements and constraints
2. ANALYZE: Architecture, dependencies, and patterns
3. REASON: Best implementation approach and trade-offs
4. SYNTHESIZE: How components integrate with existing code
5. CONCLUDE: Implement with clear, maintainable solution
